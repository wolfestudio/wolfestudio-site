WOLF ESTÚDIO — publicação na Vercel

Opção mais fácil — GitHub + Vercel:
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta, incluindo a pasta public.
3. Na Vercel, clique em Add New > Project.
4. Escolha o repositório e clique em Deploy.
5. Não é necessário configurar banco de dados ou variáveis de ambiente.

Opção pelo terminal:
1. Instale o Node.js em https://nodejs.org
2. Abra o terminal nesta pasta.
3. Execute: npx vercel
4. Mantenha as opções padrão.
5. Para publicar em produção: npx vercel --prod
